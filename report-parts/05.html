Master Portfolio

The master portfolio sheet aggregates every Jira portfolio space into a single view, rolling up each department's projects and products with their key attributes side by side for C-levels and supportive functions within the organization.

Function Portfolio

Each delivery team maintains its own portfolio sheet, providing a consistent view of initiatives, progress, ownership, and key delivery information.

Big Picture

In addition to portfolio sheets, each delivery team uses a Jira Big Picture roadmap for daily tracking, showing how the same data supports both delivery and portfolio-level reporting.
